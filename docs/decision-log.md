## 3. 규칙 조정·유지 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 합계 행 식별 | **`fo_bbm`이 정확히 `성별합계`인 행만 합계로 인정.** `sexdstn`은 남/여만 허용하고 그 외 값은 구조 D → 보류. `fo_bbm`에 합계/총계/전체가 들어 있으나 `성별합계`가 아니면 D → 보류 | Q1, Q2. PRD는 합계가 `sexdstn`에 올 수 있다고 가정했으나 원본은 `fo_bbm`에 있었다. |
| 이중 합산 금지 | 직원 수는 상세 합을 쓰고 성별합계는 대조용. 둘이 다르면 `HOLD(CONFLICT)`. 상세 행이 없으면(T 구조) 성별합계를 쓰되 "검증 없이 사용" 비고를 남긴다 | 삼성 사례 |
| 급여총액 출처 | 성별합계 남·여가 둘 다 있으면 그것을 사용. 상세 행 급여가 모두 있으면 합계와 대조(불일치 시 보류). 상세만 완전하면 상세 사용. 일부만 있으면 보류 | 삼성은 급여가 성별합계에만 있음 |
| 남·여 공시 평균 | 성별합계 행 값을 우선, 없으면 **부문이 1개일 때만** 그 부문 행. 부문이 여러 개인데 합계 행이 없으면 "성별 단일 공시값 없음"(합치지 않음) | Q2, Q4 |
| 전체 평균 | 항상 "원본에 없음". 남·여 단순평균·가중평균·분모 역산 금지 | Q4 |
| 단위 | PRD 6.3 유지(화이트리스트, 크기 추정 금지, 혼재·일부 표기·인식불가는 보류). 실제 표기 사례는 없어 **합성 F06~F08로만 검증** | Q3 |
| 인당 매출 범위 | OFS 기본 유지. CFS 회사는 값을 만들지 않고 `NOT_COMPARABLE` | PRD 4.3 |
| 재무제표 기간 정합 | API에 기간 종료일이 없어 **`stlm_dt`의 연도 = 선택 사업연도**만 확인, 아니면 인당 매출 `HOLD`. 재무제표 자체의 기간 종료일 대조는 불가 | 매출 응답 구조 |
| 직원 수 0명 | `HOLD(ZERO_HEADCOUNT)` | PRD 6.2 |
