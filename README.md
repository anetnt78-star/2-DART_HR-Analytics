# HR Analytics 에이전트 (1차: 두 기업 · 한 연도 비교)

DART 사업보고서 `empSttus`·`fnlttSinglAcntAll`을 검증해 두 상장기업의 인력·급여·인당 매출을 비교하고, 검증된 값만으로 AI 브리핑과 후속 대화를 제공합니다. 기획은 `PRD.md`, 원본 확인 결과는 `docs/decision-log.md`에 있습니다. (추이·예상은 2차 범위라 아직 없습니다.)

## 실행 (초보자용)
1. Node.js 설치(LTS) — 터미널에서 `node --version`이 나오면 됩니다.
2. 이 폴더에서 `npm install`
3. `.env`는 이미 빈 항목으로 준비되어 있습니다. **키를 입력하지 않아도** 합성 예시 모드로 실행됩니다.
4. `npm run dev` → 브라우저에서 http://localhost:3000

## 키 입력 (실제 모드)
`.env`를 열어 값을 채웁니다. (`.env`는 `.gitignore`에 있어 저장소에 올라가지 않습니다.)
```
OPENDART_API_KEY=발급받은_OpenDART_키
OPENAI_API_KEY=발급받은_OpenAI_키
OPENAI_MODEL=사용할_모델명     # 코드에 기본값이 없어 비어 있으면 AI가 "모델 미설정"으로 꺼집니다
```
키를 바꾼 뒤에는 서버를 다시 시작하세요. 두 키는 서로 독립입니다(DART만 있어도, OpenAI만 있어도 나머지는 동작).

## 점검 명령 (서로 독립)
| 명령 | 내용 |
|---|---|
| `npm test` (= `npm run check:synthetic`) | 합성 F01~F12·실제 원본 형태·AI 패킷 테스트. 키 불필요 |
| `npm run check:dart` | 고유번호 인덱스 → `empSttus` → `fnlttSinglAcntAll` → 필수 7개 필드 확인 |
| `npm run check:openai` | `OPENAI_MODEL`로 최소 요청 1회 |
| `npm run build:corp-index` | 상장사 검색용 인덱스(`data/corp-index.json`) 생성 |
| `npm run inspect:emp -- 삼성전자 현대자동차 2025` | 단계 0: `empSttus` 원본 7개 필드와 행 분류 출력 |

화면의 "연결 상태" 패널에서도 같은 점검을 버튼으로 실행할 수 있습니다.

## 화면 흐름
설정(모드·기업 A/B·연도) → **비교하기** → 원본 검증 패널 → 비교 카드(직원 수 · 기말 인원당 급여총액 · 인당 매출 3개가 큰 카드) → 차트 → 자동 AI 브리핑 → 후속 대화.
모드·기업·연도를 바꾸면 결과·브리핑·대화가 모두 초기화됩니다. 대화는 서버에 저장되지 않고 새로고침하면 사라집니다.

## 핵심 규칙 요약
- **기말 인원당 급여총액** = 연간급여총액 ÷ 사업연도말 직원 수 (앱 계산값, 공시 1인평균급여와 다름).
- 남·여 공시 1인평균급여는 공시값 그대로 별도 표시. 단순평균·가중평균·역산으로 전체 평균을 만들지 않습니다.
- 합계 행은 `fo_bbm="성별합계"`. 상세와 함께 더하지 않고 대조만 하며, 다르면 보류합니다.
- 단위는 비고(`rm`)의 표기(원·천원·만원·백만원·억원)만 따르고, 혼재·일부 표기·인식 불가면 보류합니다.
- 인당 매출은 별도재무제표(OFS)를 기본으로 하고, OFS/CFS 혼용·결측·0명·결산일 불일치는 보류합니다.

## 폴더
`src/lib/validate`(구조·단위·매출·기간 검증) · `src/lib/metrics`(지표·격차) · `src/lib/ai`(패킷·프롬프트·가드) · `src/lib/dart`(API 클라이언트·인덱스) · `fixtures/synthetic`(합성 F01~F12) · `tests`.

## 보안
DART·OpenAI 호출은 서버 라우트에서만 합니다. 키는 화면·로그·AI 패킷에 나오지 않습니다.
