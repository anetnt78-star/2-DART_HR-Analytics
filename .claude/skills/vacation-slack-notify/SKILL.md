# 휴가 공유 자동화 (vacation-slack-notify)

팀원이 간단한 텍스트 한 줄을 입력하면
1) Slack 팀 공지 채널에 휴가 공지를 **예약 전송**하고,
2) 휴가 당일 본인 **프로필 상태**를 `:palm_tree: 휴가 중`으로 바꾼 뒤 지정 시각에 자동 해제한다.

---

## 1. 입력 형식

```
YYYYMMDD 이름 휴가유형 [backup 대체자명]
```

- `휴가유형` = `연차` | `오전 반차` | `오후 반차` (붙여 쓴 `오전반차`, `오후반차`도 동일하게 인식)
- `backup 대체자명` 은 **선택** 입니다. 생략하면 기본 담당자(아래 설정)를 사용합니다.

### 예시 입력
```
20260923 김지훈 연차
20260923 김지훈 오전 반차
20260923 김지훈 오후 반차
20260923 김지훈 연차 backup 홍길동
```

---

## 2. 설정값 (워크스페이스 전용 — 새 워크스페이스에서는 이 값만 바꾸면 됨)

| 항목 | 값 |
|------|-----|
| Slack 워크스페이스 | `spotv-1` |
| 공지 채널명 | `#01-2-플랫폼사업-디지털서비스유닛` |
| 공지 채널 ID | `C0C55A1QQET` |
| 기본 Backup 담당자 | `고승열` |
| 프로필 상태 이모지 | `:palm_tree:` |
| 프로필 상태 텍스트 | `휴가 중` |

> 다른 워크스페이스/채널로 옮길 때는 위 표의 값만 교체하세요.
> 채널 ID를 모르면 `slack_search_channels` 로 채널명을 검색해 ID를 다시 확인하세요.

---

## 3. 동작 규칙

| 휴가 유형 | 채널 메시지 발송 시각 | 프로필 상태 종료 시각 |
|-----------|---------------------|---------------------|
| 연차 | 09:30 KST | 23:59 KST |
| 오전 반차 | 09:30 KST | 14:30 KST |
| 오후 반차 | 14:30 KST | 23:59 KST |

모든 시각은 **한국 시간(KST, UTC+9)** 기준입니다.

---

## 4. 채널 메시지 포맷

```
[휴가 공유] M/D(요일) {휴가유형}
급한 건은 연락 부탁드립니다.
Backup 담당자 : {담당자} 님
```

- `M/D` : 월/일 (앞자리 0 없이, 예: 9/23)
- `(요일)` : 한국어 요일 (월·화·수·목·금·토·일)

### 예시 출력
```
[휴가 공유] 9/23(수) 연차
급한 건은 연락 부탁드립니다.
Backup 담당자 : 고승열 님
```

---

## 5. 처리 절차 (Claude가 따라야 할 단계)

1. **입력 파싱**
   - 날짜(YYYYMMDD) → 연·월·일, 이름, 휴가유형을 추출한다.
   - `backup` 뒤에 이름이 있으면 그 이름을, 없으면 기본 담당자(`고승열`)를 사용한다.

2. **채널 ID 확인**
   - 설정값의 채널 ID(`C0C55A1QQET`)를 사용한다.
   - ID가 유효하지 않으면 `slack_search_channels` 로 채널명(`#01-2-플랫폼사업-디지털서비스유닛`)을 검색해 ID를 다시 찾는다.

3. **발송 시각 계산**
   - 연차·오전 반차 → 입력 날짜의 **09:30 KST**
   - 오후 반차 → 입력 날짜의 **14:30 KST**
   - 해당 시각을 **Unix timestamp(초)** 로 변환한다. (KST = UTC+9 이므로 09:30 KST = 00:30 UTC)
   - 제약: 지금으로부터 **최소 2분 후 ~ 최대 120일 이내** 여야 예약 가능. 벗어나면 사용자에게 알린다.

4. **채널 메시지 예약 전송**
   - `slack_schedule_message` 호출: `channel = C0C55A1QQET`, `post_at = 발송 시각 Unix timestamp`, `text = 위 4번 포맷`.
   - 이 예약은 Slack 서버가 처리하므로 **PC가 꺼져 있어도 발송된다.**

5. **프로필 상태 설정**
   - 상태 이모지 `:palm_tree:`, 상태 텍스트 `휴가 중`.
   - `status_expiration` = 프로필 상태 종료 시각(위 표)의 Unix timestamp. → 지정 시각에 **자동 해제**(PC 꺼져도 됨).
   - 참고: 상태 "시작"은 API를 호출하는 순간 적용되므로, 휴가 당일 발송 시각에 스킬을 실행해야 합니다. (상태 적용 시점에는 PC가 켜져 있어야 함)

6. **결과 보고**
   - 예약된 채널 메시지 내용, 발송 예정 시각, 프로필 상태 종료 시각을 사용자에게 요약해 알린다.
