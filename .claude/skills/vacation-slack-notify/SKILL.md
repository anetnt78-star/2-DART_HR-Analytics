# 휴가 공유 자동화 (vacation-slack-notify)

팀원이 단순 텍스트 한 줄로 휴가를 입력하면 다음 두 가지를 자동으로 처리합니다.

1. **Slack 공지 채널에 휴가 공지를 예약 전송** — 지정한 시각에 Slack 서버가 자동 발송 (PC 꺼져 있어도 됨)
2. **당일 Slack 프로필 상태를 🌴 `휴가 중` 으로 설정** — 종료 시각에 자동 해제

---

## 입력 형식

```
YYYYMMDD 이름 휴가유형 [backup 대체자명]
```

- `휴가유형`: `연차` / `오전 반차` / `오후 반차` 중 하나
- `backup 대체자명`: 선택 항목. 생략하면 아래 **기본 Backup 담당자**를 사용합니다.

### 입력 예시

```
20260923 김지훈 연차
20260923 김지훈 오전 반차
20260923 김지훈 오후 반차
20260923 김지훈 연차 backup 홍길동
```

---

## 기본 설정값

> 💡 **새 워크스페이스/팀에 적용할 때는 이 표의 값만 수정하면 됩니다.**

| 항목 | 현재값 | 변경 방법 |
|------|--------|----------|
| 공지 채널명 | `org-플랫폼사업-디지털서비스유닛` | 새 채널명으로 교체 |
| 공지 채널 ID | `C0C55A1QQET` | `slack_search_channels`로 재조회 후 교체 |
| 기본 Backup 담당자 | 고승열 | 이 파일의 기본값 수정 |
| 프로필 상태 이모지 | `:palm_tree:` (🌴) | 팀 규칙에 맞게 수정 |
| 프로필 상태 텍스트 | `휴가 중` | 팀 규칙에 맞게 수정 |
| 타임존 | KST (UTC+9) | 팀 기준 시간대로 수정 |

---

## 동작 규칙

| 휴가 유형 | 채널 메시지 발송 시각 | 프로필 상태 종료 시각 |
|----------|---------------------|---------------------|
| 연차 | 09:30 KST | 23:59 KST |
| 오전 반차 | 09:30 KST | 14:30 KST |
| 오후 반차 | 14:30 KST | 23:59 KST |

---

## 채널 메시지 포맷

```
[휴가 공유] M/D(요일) {휴가유형}
급한 건은 연락 부탁드립니다.
Backup 담당자 : {담당자} 님
```

### 출력 예시

```
[휴가 공유] 9/23(수) 연차
급한 건은 연락 부탁드립니다.
Backup 담당자 : 고승열 님
```

- `M/D`: 월/일 (앞자리 0 없이). 예) 2026-09-23 → `9/23`
- `(요일)`: 한글 요일 한 글자 (월/화/수/목/금/토/일)
- `{휴가유형}`: 입력한 휴가유형 그대로 (연차 / 오전 반차 / 오후 반차)
- `{담당자}`: backup 지정값, 없으면 기본 Backup 담당자

---

## 실행 절차

### 1단계. 입력 파싱
입력 문자열을 공백으로 나누어 아래 값을 추출합니다.
- **날짜**: 앞 8자리 `YYYYMMDD` → 연/월/일
- **이름**: 날짜 다음 토큰
- **휴가유형**: `연차` / `오전 반차` / `오후 반차` (두 단어로 이루어진 반차 주의)
- **backup 담당자**: `backup` 키워드 뒤의 이름. 없으면 기본값(고승열)

> ⚠️ 입력 형식이 맞지 않거나 휴가유형을 알 수 없으면, 추측하지 말고 사용자에게 올바른 형식을 안내하고 다시 입력을 요청하세요.

### 2단계. 채널 ID 확인
- `slack_search_channels`로 공지 채널명을 조회해 **채널 ID**를 얻습니다.
- 기본 설정값의 채널 ID(`C0C55A1QQET`)가 유효하면 재조회를 생략해도 됩니다.

### 3단계. 발송 시각 계산 (채널 메시지 예약)
- 휴가유형별 발송 시각을 적용합니다.
  - 연차·오전 반차 → **09:30 KST**
  - 오후 반차 → **14:30 KST**
- `입력 날짜 + 발송 시각`을 **KST(UTC+9) 기준 Unix timestamp(초)** 로 변환합니다.
- **제약**: 예약은 현재 시각 기준 **최소 2분 후 ~ 최대 120일 이내**만 가능합니다.
  - 발송 시각이 이미 지났거나 범위를 벗어나면 사용자에게 알리고 어떻게 처리할지 확인하세요.

### 4단계. 채널 메시지 예약 전송
- `slack_schedule_message`를 호출합니다.
  - `channel`: 2단계에서 얻은 채널 ID
  - `post_at`: 3단계에서 계산한 Unix timestamp
  - `text`: 위 **채널 메시지 포맷**으로 작성한 문자열
- ✅ 이 단계는 Slack 서버가 처리하므로 **PC가 꺼져 있어도** 예약대로 발송됩니다.

### 5단계. 프로필 상태 설정
- **시작**: 발송 시각(연차·오전반차 09:30 / 오후반차 14:30)에 프로필 상태 변경 API를 호출합니다.
  - 상태 이모지: `:palm_tree:`
  - 상태 텍스트: `휴가 중`
  - ⚠️ 상태를 **시작**시키는 시점에는 **PC가 켜져 있어야** 호출됩니다.
- **종료**: `status_expiration` 파라미터에 **종료 시각의 Unix timestamp**를 전달합니다.
  - 종료 시각: 연차·오후반차 → 23:59 KST / 오전반차 → 14:30 KST
  - ✅ 이 값을 넣으면 **PC가 꺼져 있어도** 종료 시각에 상태가 자동 해제됩니다.

## 주의사항
- **반차 입력 주의**: `오전 반차`, `오후 반차`는 공백이 포함된 두 단어이므로 파싱 시 `반차` 앞 단어(오전/오후)까지 함께 읽어야 합니다.
- **타임존**: 모든 시각 계산은 KST(UTC+9) 기준입니다. 서버/실행 환경이 다른 시간대면 반드시 KST로 변환하세요.
- **예약 제약(2분~120일)** 을 벗어나는 날짜는 예약이 거부됩니다. 미리 확인하세요.
- Slack MCP 도구 이름(`slack_schedule_message`, `slack_search_channels`, 프로필 상태 변경 도구)은 연결된 Slack 커넥터에 따라 다를 수 있습니다. 실제 사용 가능한 도구 이름으로 매칭해 호출하세요.
